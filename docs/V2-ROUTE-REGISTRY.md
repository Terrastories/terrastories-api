Named non-community exceptions: `/health`, `/ready`, `/v2/auth/*`, `/v2/bootstrap/*`, and null-community `super_admin` own profile photo on `/v2/media/:id`. `/explore/*` is the transitional Explore read adapter; Fastify `/api/v1/*` is frozen coexistence and excluded from V2.                                                                                                                                                                                                                                                                                                                    | §9, `src/hono-app.ts`, `src/explore-adapter.ts`                               |

Exceptions: `/v2/public/communities/:slug/*` (public slug locator), `/v2/auth/prelogin` / `login` / `recovery/redeem` (optional `communitySlug` locator), `/v2/bootstrap/claim` (`ClaimToken.communityId`), `/v2/admin/communities/:id/*` (operational lifecycle only), and steward-initiated `POST /v2/community/withdrawal` / `POST /v2/community/erasure` when `actor.communityId` is `null` (a `super_admin` designated steward supplies an explicit `communitySlug` or `communityId` locator in the request body, verified against the community's recorded steward designation for `actor.id`). | §6.2, §7, §9                                                                  |
| **Middleware order**        | Unauthenticated `/v2/public/*`, `/v2/auth/prelogin`, `/v2/auth/login`, `/v2/auth/recovery/redeem`, and `/v2/bootstrap/*` must register before (or bypass) the `/v2/*` session gate. Static segments (`/search`, `/near`, `/preview`, `/export`, etc.) register before `/:id`.                                                                                                                                                                                                                                                                                                                                                                                                                                                             | `src/hono-app.ts`, `PHASE-1-PLAN.md`                                          |
| **IDs**                     | Core relational entities (`Community`, `User`, `Story`, `Place`, `Speaker`): positive decimal integers `1..2147483647` (`MAX_DATABASE_ID`). `File`: UUID string. `Session`: opaque string ID. Auxiliary IDs (`LoginCode`, `ClaimToken`, `AuditEntry`, `ImportManifest`, `Attachment`, `ExternalMediaLink`): see [Open questions](#open-questions).                                                                                                                                                                                                                                                                                                                                                                                        | `src/shared/types/public.ts`, `src/hono-app.ts`, §6.8–§6.9                    |
| **Timestamps**              | Stored at millisecond precision on every backend (`timestamp(3)` on PostgreSQL; Unix ms integer on SQLite/D1). JSON wire format is an open question (`Explore` emits ISO 8601).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | §8, `EXPLORE-ADAPTER.md`                                                      |
| **Error envelope**          | On `main`: `{ "error": string, "code"?: string }` (`PublicApiError` also defines `details?`; see [Open questions](#open-questions)). Hidden/withheld/cross-community rows under §6.4a and `#162` return `404 { "error": "Not found" }`; role-blocked route families return `403 { "error": "Forbidden" }`. Auth/login/code/claim failures return uniform non-enumerating errors (`401`/`400` without leaking slug, identifier, ambiguity, or throttle state).                                                                                                                                                                                                                                                                             | `src/hono-app.ts`, `src/worker.ts`, §6.2, §6.4a, §6.8, `scripts/qa/README.md` |
| **Pagination**              | SPEC requires deterministic ordering (`newest`, `title` asc/desc + stable ID tie-breaker) and bounded responses; keyset vs offset pagination is open (see [Open questions](#open-questions)). `Explore` uses `limit` (1–100) / `offset`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | §4, §9, `EXPLORE-ADAPTER.md`                                                  |
| **Security headers & CSRF** | Every response sets `Cache-Control: no-store`, `X-Content-Type-Options: nosniff`, `Content-Security-Policy: default-src 'none'; sandbox`. Media downloads add `Content-Disposition: attachment`. Non-GET/HEAD/OPTIONS routes enforce `Origin` / `Sec-Fetch-Site` CSRF checks against `PUBLIC_ORIGIN` / `CORS_ORIGINS`. Cookie `ts_session` is `HttpOnly`, `SameSite=Strict`, `Secure` (unless dev or field-kit plain-HTTP opt-in).                                                                                                                                                                                                                                                                                                        | `src/hono-app.ts`, §7                                                         |
| **Read visibility (§6.4a)** | Role × resource × association outcomes from `src/policy/read-rules.ts`: `visible`, `with readable stories` (reachable only via ≥1 readable story), `hidden` (404). `#162` override hides `isRestricted = true` or unknown-privacy rows for every role on all read surfaces.                                                                                                                                                                                                                                                                                                                                                                                                                                                               | §6.4a, `src/policy/read-rules.ts`                                             |

4. **Sole-admin / all-admins-unreachable / `super_admin` lockout (§6.10, §7):** Operator-supervised, community-authorized re-bootstrap or steward-designation remedy when all admins (or a `super_admin`) lose both password and recovery codes (#187, #188).
5. **Export rate-limit & Workers Free feasibility threshold (§7):** Settled by Slice 13a (`src/shared/export-policy.ts`: 8/hour per community, 5/hour per admin account, 15m token TTL; expiry-bound Node timers plus a restart-safe one-minute export sweep on Node and Workers (maximum one-minute scheduling grace with healthy storage and within the 5-job Workers / 20-job Node tick capacity), and community sweeps on every authorized export/download request. Failed storage operations remain retryable and may extend retention until storage recovers; a reclaimed writer cannot close cleanup until it acknowledges that writing has stopped. Limits: 10,000 rows / 30 files / 50 MiB media / 64 MiB archive / 8 MiB manifest on Workers Free (64 MiB manifest on Node). Snapshot SQL guards total text bytes before fetching rows; serialization counts escaped UTF-8 bytes before allocating canonical JSON. Failed generation attempts count against both sliding-window quotas). (#187).

7. **Withdrawal state & un-withdraw reversal (§7):** Whether community-initiated withdrawal is distinct from operator `disabled` and whether a community-administered reversal exists (#187).
8. **Legacy archive transfer before erasure & destruction verification (§7):** Whether erasure must offer return/transfer of a held archive before destruction, and verification beyond steward self-attestation (#187).
9. **Workers Paid erasure bound (§7):** Whether to accept the 31-day worst case (≤24h live deletion + 30-day Time Travel) or run Paid with a shorter Time-Travel/backup policy (#187).
10. **Member self-export while withdrawn (§7):** Whether a non-admin member of a withdrawn community can export their own profile and contributions while community surfaces are disabled (#187).

### API-contract details not yet pinned by `SPEC-V2.md`

11. **Pagination style (§4, §9):** Keyset/cursor pagination vs offset (`limit`/`offset` or `page`/`limit`) for canonical `/v2/public/*` and `/v2/*` list endpoints.

13. **Error envelope extension (§9):** Whether canonical V2 standardizes `{ error, code, details? }` (`PublicApiError`) for validation failures or keeps `main`'s `{ error, code? }` across all domains.
14. **First-login recovery-code confirmation (§7):** RESOLVED (#254). Confirmation is completed inside the `POST /v2/auth/recovery-codes` generation response; there is no separate confirm route (codes are shown once and stored hashed, so a confirm step would add state without proof). Production entrypoints (`src/worker.ts`, `src/hono-server.ts`) enable `requireRecoveryCodes`: a community `admin` with no active `recovery` LoginCode gets `403 { code: 'recovery_codes_required' }` on every `/v2/*` route except `/v2/auth/*` until they generate codes. The gate is derived from existing data (`recoveryCodesConfirmed`), needs no marker column, and covers every community admin, which includes migrated and `admin_issued`-enrolled admins. Super admins and stewards generate codes optionally and are not gated.
15. **Media uploads >100 MB on Workers Free (§5, #140):** Exact max file size, per-community storage quota, and whether launch Workers Free adds multipart/presigned direct-to-R2 initiation/completion routes for objects >100 MB or defers >100 MB to self-hosted/field-kit.
